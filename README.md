# Re:Struct (リストラ)
**〜遊んで学ぶ3D点群撮影ゲーム：SfMを活用した精度体験型Webアプリ〜**  
*“Gamified SfM Training: An Interactive Web App for 3D Point Cloud Accuracy”*

---

## 🎮 プロジェクト概要
Re:Struct は **Structure-from-Motion (SfM)** を活用した学習型 Web アプリです。  
カメラで物体を撮影すると即座に点群を再構成し、**精度をスコア化して可視化**します。  
撮影条件（枚数・角度分布）がスコアに直結するため、**遊びながら撮影スキルを学習可能**です。

---

## ✨ 特徴
- **カメラで撮影 → 点群生成 → 精度スコア化** の一連処理をリアルタイムに体験
- 精度指標（RMSE）を **流れるように表示**
- **撮影条件とスコアの関係**を直感的に学べる
- **Three.js** による 3D点群表示（自由に回転・拡大縮小）
- 遊び感覚で **未来の3D地図作りに参加**できる

---

## 🛠 手法
- **撮影制御**  
  - Webカメラで連写（解像度・露出固定）

- **SfM再構成**  
  - MATLAB 高レベル関数による軽量再構成  
  - ORB/SIFT特徴点抽出 → 近傍マッチング → バンドル調整  
  - 低解像度＋簡易BAで **30〜90秒以内に点群生成**

- **精度評価**  
  - 基準点群（十分な枚数で事前作成）と比較  
  - ICPで位置合わせ → RMSE / P95 / Hausdorff距離を算出  
  - JSON (`metrics.json`) に出力 → Webが `fetch` で取得  
  - Three.jsで点群表示＋数値はカウントアップアニメで提示

---

## 🌍 背景
- 自動運転車の高精度3D地図化が進む一方、MMSや航空レーザではカバーできない場所が存在
- 現地で写真を撮影し SfM により点群を補完することが有効
- 撮影方法次第で精度が大きく変動するが、現状の取り組み（例: ジオクエスト）は「ポイント付与」に留まりモチベーションが続かない

---

## 🎯 目的
- 人が **「遊びながら」点群を取得する動機付け** を提供
- 効率的な撮影方法（角度・枚数）のトレーニングを支援
- 将来的には：
  - 群衆参加型SfMで欠損領域を補完 → 自動運転の安全性を強化  
  - 建築物・インフラ維持管理の **低コスト3D化・自動化** に発展
